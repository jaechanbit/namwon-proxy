# 2026 남원시 학원연합회 임시총회 위임장 온라인 작성기

원장님들께서 스마트폰이나 PC에서 간편하게 인적사항을 입력하고 서명(또는 직인 날인)한 뒤, **카카오톡이나 문자로 사무국장에게 바로 전송**할 수 있는 웹사이트입니다.

---

## 🌟 주요 기능

1. **실시간 A4 공식 양식 미리보기**
   - 원본 PDF 문서와 100% 동일한 서식 및 규격 적용
   - 학원명, 성명, 사유, 일자 입력 시 실시간 반영
2. **2가지 서명 모드 지원**
   - ✍️ **직접 전자 서명**: 마우스나 스마트폰 터치스크린으로 부드럽게 직접 서명 (지우기 / 펜 색상 변경 가능)
   - 🔴 **전자 도장(인) 자동 생성**: 서명이 어려운 분들을 위해 입력된 원장님 성명으로 한국식 정통 인장(원형, 타원형, 사각형 직인) 자동 생성 날인
3. **카톡 및 문자 전송에 최적화된 내보내기**
   - 💬 **카톡/문자 전송용 이미지 저장 (PNG)**: 스마트폰 갤러리에 깔끔하게 저장되어 카톡으로 바로 보내기 최적! (Web Share API 지원)
   - 📄 **정식 규격 PDF 다운로드**: 인쇄 및 보관용 고화질 A4 PDF
   - 🖨️ **즉시 인쇄**: 브라우저 인쇄 다이얼로그 즉시 실행
4. **완벽한 모바일 반응형**
   - 스마트폰 화면에서도 한 손으로 편하게 입력 및 서명 가능

---

## 🚀 로컬 실행 방법

1. 폴더 내 `실행하기.bat` 파일을 더블클릭합니다.
2. 기본 웹 브라우저가 자동으로 실행되며 `http://localhost:8080`으로 접속됩니다.
3. 입력 및 서명 후 **[카톡/문자 전송용 이미지 저장]** 또는 **[PDF 다운로드]**를 클릭하세요.
